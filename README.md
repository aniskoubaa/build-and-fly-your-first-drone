# Build & Fly Your First Drone: code

Code for the YouTube series **Build & Fly Your First Drone** by Anis Koubaa
([English playlist](https://www.youtube.com/playlist?list=PLRkbz9iyd71M)).
Free course with a free certificate: https://learn.xeducation.ai/courses/build-and-fly-your-first-drone

| Episode | Folder | Video |
|---|---|---|
| 13. ROS 2 + PX4 for beginners | [`13-ros2-px4/`](13-ros2-px4/) | https://youtu.be/-oroXuus-3I |

Everything runs in simulation (PX4 SITL + Gazebo). Test on a real drone only after it works in simulation,
and first without propellers.
